# 🏥 Smart Hospital Management System

## 📌 Project Overview

Smart Hospital Management System is a full-stack web application developed to digitize hospital operations such as appointment booking, prescription management, doctor management, patient records, and medical store workflow.

The system contains multiple modules with role-based authentication and dashboards.

---

# 🚀 Features

## 👨‍💼 Admin Module

* Add / Update / Delete Doctors
* Manage Patients
* View All Appointments
* Manage Medical Store Users
* Monitor Hospital Activities

---

## 👨‍⚕️ Doctor Module

* View Assigned Appointments
* Approve / Reject Appointments
* Send Digital Prescriptions
* Manage Patient Consultations

---

## 🧑‍🤝‍🧑 Patient Module

* Register / Login
* Book Appointments
* View Appointment Status
* Access Online Prescriptions

---

## 💊 Medical Store Module

* View Patient Prescriptions
* Search Prescription Tokens
* Provide Medicines Digitally
* Manage Prescription Workflow

---

# 🔐 Security Features

* Login Validation
